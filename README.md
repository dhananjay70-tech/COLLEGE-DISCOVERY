# 🎓 College Discovery Platform

A full-stack College Discovery Platform inspired by Collegedunia that helps students explore colleges, courses, exams, scholarships, and admission details in one place.

## 🚀 Features

* 🔍 Search and filter colleges
* 🏫 College details page
* 📚 Course information
* 📝 Admission details
* 💰 Scholarship information
* ⭐ College ratings and reviews
* 📱 Responsive design
* 🔐 User authentication
* ❤️ Save favorite colleges

## 🛠️ Tech Stack

### Frontend

* React.js
* Vite
* Tailwind CSS
* React Router DOM
* Axios

### Backend

* Node.js
* Express.js
* MongoDB
* JWT Authentication

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/dhananjay70-tech/COLLEGE-DISCOVERY.git
cd COLLEGE-DISCOVERY
```

### Frontend Setup

```bash
cd client
npm install
npm run dev
```

### Backend Setup

```bash
cd server
npm install
npm start
```
